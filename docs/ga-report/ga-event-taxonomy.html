2. 구현 방식

  • 가상 경로로 page_view 전송. 이 블로그는 #/post/글아이디 형태의 해시 주소를 씁니다. GA는 주소의 # 뒤를 구분하지 못해 모든 페이지가 하나로 합쳐지므로, GA 기본 page_view를 끄고(send_page_view: false) 화면이 바뀔 때마다 page_location을 /blog/post/글아이디처럼 가상 경로로 직접 보냅니다.
  • 글 상세의 페이지 제목은 글 제목. GA의 "페이지 및 화면" 보고서에서 글별 조회가 제목으로 구분됩니다.
  • 집계에서 제외하는 것. 비공개 글과 임시저장 글, 글쓰기·카테고리 관리·로그인 화면, 관리자로 로그인한 브라우저, 로컬 개발 환경.

4. 이벤트 택소노미

모든 이벤트의 상태는 구현 완료입니다. 글 상세의 page_view와 article_scroll은 공개된 글에서만 전송합니다.

이벤트발생 조건매개변수목적
page_view 홈, 전체 글, 글 상세 화면이 열릴 때. 화면 이동마다 한 번 page_title 홈 / 전체 글 / 글 제목
page_location 가상 경로
page_type home · list · post
글 상세만: post_id, post_category		 홈과 글별 방문, 페이지별 사용자와 조회수
category_click 카테고리를 선택할 때 category 카테고리 이름 (전체를 고르면 전체)
click_location home_hero · list_filter · post_meta		 카테고리 관심도
article_select 글 제목, 이미지, [읽기], 목차 항목, 목록 항목, 다음 글 카드를 눌러 글로 이동할 때 post_id, post_title, post_category
click_location home_card · home_toc · list_index · next_article		 홈에서 글로 이동, 이동 경로별 비교
article_scroll 글 본문의 50%, 90% 지점을 지날 때. 지점마다 글 방문당 한 번 post_id, post_title, post_category
scroll_depth 50 · 90		 글 읽기 깊이 추정
select_palette 색 조합을 바꿀 때 (부가 이벤트) palette 선택한 조합 이름 화면 색 선호

읽기 깊이는 본문 영역 높이를 기준으로 계산합니다. 한 화면에 다 들어오는 짧은 글은 50%와 90%가 거의 동시에 전송됩니다.

6. GA 콘솔 설정

맞춤 정의 등록. 매개변수는 등록해야 보고서에서 글별, 카테고리별로 나눠 볼 수 있습니다. 등록하지 않으면 이벤트 개수만 보입니다. 등록 후 반영에는 하루 정도 걸릴 수 있습니다.

이름 (이벤트 매개변수)종류 · 범위용도
post_id맞춤 측정기준 · 이벤트글 구분 (제목이 같은 글 방지)
post_title맞춤 측정기준 · 이벤트글별 이벤트 수 보기
post_category맞춤 측정기준 · 이벤트카테고리별 글 조회와 읽기 깊이
category맞춤 측정기준 · 이벤트카테고리 클릭 집계
click_location맞춤 측정기준 · 이벤트클릭 위치별 비교
page_type맞춤 측정기준 · 이벤트홈, 전체 글, 글 상세 구분
scroll_depth맞춤 측정기준 · 이벤트50%와 90% 구분. 숫자 합계가 필요하면 맞춤 측정항목으로도 등록

향상된 측정. 스트림 설정의 향상된 측정에서 "기록 이벤트에 따른 페이지 변경"을 꺼야 합니다. 켜 두면 직접 보내는 page_view와 겹쳐 두 번 집계될 수 있습니다.

7. 보고서 보는 방법

알고 싶은 것보는 곳
홈 방문자 수보고서 → 참여도 → 페이지 및 화면에서 홈의 사용자와 조회수
가장 많이 본 글같은 보고서에서 페이지 제목(글 제목)별 조회수
가장 많이 끝까지 읽은 글참여도 → 이벤트 → article_scroll, 측정기준 post_title과 scroll_depth
인기 카테고리이벤트 → category_click, 측정기준 category
홈에서 어디를 눌러 글로 가는가이벤트 → article_select, 측정기준 click_location
이탈참여도 → 페이지 및 화면(종료수), 탐색 분석
유입, 지역, 기기, OS보고서 → 획득, 사용자 → 인구통계, 기술
