## 문서 규칙

1. 파일명은 영어 소문자와 하이픈으로 쓴다. 날짜가 필요하면 `2026-11-17`처럼 쓰고, 버전은 파일명에 넣지 않고 문서 안 표에 적는다.
2. 제목은 한 줄로 문서 이름만 쓴다. 콜론이나 괄호로 버전과 용도를 덧붙이지 않는다. PRD 제목은 `<대상> PRD`로 쓴다.
3. 제목 바로 아래에 `> 목적:`으로 시작하는 한 줄을 둔다.
4. 이전 버전의 PRD는 `prd/archive/`로 옮기고 이 목록의 표에 남긴다.
5. 새 문서를 만들면 이 목록에 한 줄을 같이 추가한다.
