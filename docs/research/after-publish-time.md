# 글 올리는 시간 구현 후 측정값

> 목적: PRD 5.1의 올리는 시간(KR2, 구현 전보다 30% 짧게)을 구현 전과 같은 방식으로 재서 비교하고, 측정 중에 드러난 문제를 남긴다. 구현 전 값과 방법은 [baseline-publish-time.md](baseline-publish-time.md)에 있다.

## 측정 방법

구현 전과 같다. 시험 본문(218자)을 미리 채우고, 홍지영이 제목, 요약을 정해 발행을 누른다. 시간은 페이지 안의 타이머가 쟀다. 시작은 제목 칸의 첫 입력, 끝은 발행 버튼 클릭이다. 생각을 시작하는 순간 제목 칸에 아무 글자나 먼저 입력해 타이머를 시작했다. 구현 후에는 본문 아래 "AI 제안 받기"를 눌러 제안을 쓰거나 고쳐 쓰는 과정이 들어간다.

기준 시간은 구현 전 77.8초이고 목표는 30% 단축, 즉 54.5초 이하이다.

## 결과

| 시도 | 걸린 시간 | 구현 전 대비 | 제목 | 요약 | AI 호출 | 제안 사용 |
|---|---|---|---|---|---|---|
| 첫 시도 | 17.6초 | 77% 단축 | 25자 | 116자 | 1회 | 제목, 요약, 카테고리 모두 제안 그대로 |
| 둘째 시도 | 중단 | 해당 없음 | 해당 없음 | 해당 없음 | 5회(전부 사용) | 발행하지 않음 |
| 셋째 시도 | 32.5초 | 58% 단축 | 26자 | 127자 | 5회(전부 사용) | 카테고리는 그대로, 제목과 요약은 고쳐 씀 |

- 첫 시도(한국 시각 2026-11-25 10:11:45 ~ 10:12:03)와 셋째 시도(10:38:52 ~ 10:39:24) 모두 목표를 넘었다. 구현 전과 같은 카테고리(기획), 표지 비움 조건이다.
- 둘째 시도는 AI 제안을 5번 받았지만 쓸 만한 제목이 없어 중단했다. 이 내용은 아래 "측정 중에 드러난 문제"에 적었다.
- 시도마다 쓰인 프롬프트가 다르다. 첫 시도는 처음 프롬프트, 셋째 시도는 읽는 사람 문장과 제목 규칙을 넣은 뒤이고 겹문장 금지 규칙 전이다. 지금 코드의 프롬프트로 다시 재지는 않았다.

## 측정 중에 드러난 문제와 조치

| 문제 | 관찰 | 조치 |
|---|---|---|
| 제안 제목이 쓸 만하지 않음 | 첫 시도 뒤 지영이 제목이 마음에 들지 않았다고 했고, 둘째 시도에서 5번 받아도 쓸 만한 제목이 없었다. 본문의 용어(전환, 이탈)를 그대로 가져와 어렵고, 글에서 무엇을 얻는지 보이지 않았다 | 프롬프트에 읽는 사람과 제목 규칙을 넣음(D37) |
| 다시 받으면 같은 제안이 반복됨 | 5번 중 1번과 3번, 2번과 4번이 같았다. 시험 호출 6번에서도 같은 제목이 겹쳤다 | 이미 나온 제안을 함께 보내 다른 제안을 쓰게 함(D37). 고친 뒤 같은 글에서 5번 받은 제목이 모두 달랐다 |
| 절이 겹친 어색한 제목 | "가입 화면을 언제 띄워야 사용자가 남는지 정하는 기준" 같은 제목이 후보로 나옴 | 겹문장 금지 규칙을 넣음(D37). 시험 8번에서 제목이 18~25자로 짧아졌고 한 가지 이야기만 담았다. 완전히 막지는 못한다(말투가 딱딱한 "까닭", 업계 말 "이탈"이 남음) |
| 발행 확인창이 취소됨 | 내장 브라우저가 "표지가 비어 있어 이대로 발행할까요?" 확인창을 열지 못해 자동으로 취소했다. 타이머는 발행 버튼을 누른 순간 멈춰 있어 값에는 영향이 없다 | 측정용 페이지에서만 확인창을 통과시키고 다시 발행함. 일반 브라우저에서는 이 창이 정상으로 뜬다 |

## 한계

1. 한 번 쟀고 비교는 구현 전 1회 대 구현 후 2회이다. 한 번의 비교라는 점을 결과에 함께 적는다.
2. 구현 전은 데이터가 저장되지 않는 로컬 미리보기였고 구현 후는 실제 블로그 에디터이다. 타이머가 발행 버튼을 누르는 순간까지만 재서 저장 시간은 들어 있지 않다.
3. 같은 시험 본문을 세 번째 보는 것이라 제목, 요약을 정하기 쉬웠을 수 있다.
4. 첫 시도는 제안을 그대로 썼고 셋째 시도는 고쳐 썼다. 실제 사용은 이 둘 사이이다.
5. 타이머 시작은 홍지영이 직접 한 입력이라 생각을 시작하는 순간에 맞췄는지는 본인 보고이다.
6. 시험 글은 비공개로 저장했다. 측정 뒤 지운다.
