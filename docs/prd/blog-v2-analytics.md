# 블로그 2차 개선 PRD: 데이터 분석 강화

| 항목 | 내용 |
|---|---|
| 문서 상태 | 초안 (검토 요청) |
| 작성일 | 2026-11-18 |
| 대상 서비스 | 기획 노트 (React SPA, GitHub Pages, Firebase) |
| 분석 도구 | Google Analytics 4 (GA4) |
| 관련 문서 | GA 이벤트 택소노미(`docs/ga-report/ga-event-taxonomy.pdf`), 작업 기록(`docs/work-log.md`) |

## 1. 배경과 목적

1차 개선으로 디자인 개편, GA4 연결, 글별 링크 미리보기(OG)까지 갖췄다. 그러나 "어떤 글이 잘 읽히는가"를 판단하기에는 측정이 부족하다. 2차의 목적은 **블로그 콘텐츠 성과를 GA4 안에서 충분히 분석할 수 있게 하는 것**이며, 현재 GA에서 누락되었거나 확인할 수 없는 항목을 채운다.

## 2. 현황과 문제

글별 조회수, 홈에서 글로의 이동, 카테고리 클릭, 지역·기기·유입 경로·이탈은 현재 측정 가능하며 이번 범위에서 변경하지 않는다. 아래는 측정이 부족하거나 확인할 수 없는 항목이다.

| 번호 | 알고 싶은 것 | 현재 | 문제와 영향 | 해소 |
|---|---|---|---|---|
| G1 | 글 길이를 반영한 체류 시간 | GA 기본 "평균 참여 시간"만 존재, 글 길이와 발행일 미전송 | 길이가 다른 글끼리 공정한 비교 불가, 신규/기존 글 구분 불가 | R1 |
| G2 | 완독 | `article_scroll` 50%, 90%만 존재 | 짧은 글은 열자마자 도달하고 빠른 스크롤도 완독으로 집계되어 완독률 과대평가 | R2 |
| G3 | 공유, 관심 주제 | 링크 복사 버튼은 있으나 이벤트 없음, 검색 이벤트 없음 | 공유 의도와 독자 관심 주제 파악 불가 | R3 |
| G4 | 좋아요, 스크랩 | 기능 없음 | 반응 지표 부재 | R4 |
| G5 | 공유 링크를 통한 방문 | 공유 경로 구분 수단 없음 | 공유로 유입된 방문 식별 불가 | R5 |
| G6 | 운영자 방문 제외 | 로그인한 적 있는 브라우저에서만 제외 | 운영자 방문이 섞일 수 있음 | R7 |
| G7 | 글별 지표 비교, 인기 글 | 글별 지표를 모아 보는 보고서와 판단 기준 없음 | 인기 글 판단이 수작업 | R6, 후속 대시보드 |

## 6. 요구사항 상세

### R1. 이벤트 공통 매개변수 보강 `P0`
모든 글 관련 이벤트에 읽는 시간(`read_minutes`)과 발행일(`post_published`)을 추가한다.
- 수용 기준: 글별 탐색 분석에서 글 길이와 발행일로 구분 가능

### R2. 완독 판정 개선 `P0`
- `article_read`: 글 방문당 1회, 아래 두 조건을 모두 만족할 때 전송한다.
  1. 본문 90% 지점을 지났다.
  2. 화면이 앞에 있던 활성 시간이 읽는 시간의 40% 이상이다. 단, 최소 10초.
- `article_time`: 활성 시간 15, 30, 60, 120초 도달 시 각각 1회 전송한다.
- 기존 `article_scroll`(50, 90)은 읽기 깊이 분석용으로 유지한다.
- 수용 기준: 열자마자 끝까지 내리는 테스트에서는 `article_read`가 발생하지 않고, 정상 속도로 읽는 테스트에서는 1회만 발생

### R3. 공유, 검색 이벤트 `P0`
- `share`: 링크 복사 버튼 클릭 시 전송
- `search`: 전체 글 검색창 입력이 멈춘 뒤(0.8초) 1회 전송. 빈 검색어와 1글자는 전송하지 않음
- 수용 기준: 두 동작이 DebugView에 1회씩 표시됨

### R4. 좋아요, 스크랩 기능 `P1`
- 글 상세 화면에 좋아요, 스크랩 버튼을 추가한다. 로그인 없이 사용하며, 방문자별 1회만 집계되고 다시 누르면 취소된다.
- 인증: Firebase 익명 인증
- 저장: Firestore `posts/{글ID}/reactions/{사용자ID}` 문서에 `like`, `scrap` 불리언 저장. 개수는 화면에서 집계한다.
- 보안 규칙: 쓰기는 본인 문서만, 읽기는 공개
- 수용 기준: 동일 사용자가 여러 번 눌러도 1회로 집계, 취소 시 감소, 규칙으로 타인의 반응 변경 불가

### R5. 링크 복사 UTM 부착 `P1`
- 링크 복사 시 `utm_source=share&utm_medium=copy_link`를 주소에 붙인다.
- 링크 미리보기(OG)와 canonical 주소에는 영향이 없어야 한다.
- 수용 기준: 해당 주소로 접속하면 GA 획득 보고서에 소스/매체가 `share / copy_link`로 표시됨

### R6. 인기 글 판단 기준 `P1`
글별로 아래 지표를 산출하고, 조회수 하나가 아니라 점수로 판단한다. 같은 지표 정의를 후속 범위의 글별 지표 대시보드(7장)가 이어받는다.

| 지표 | 정의 |
|---|---|
| 조회수, 활성 사용자 | GA 기본 |
| 평균 참여 시간 | GA 기본 |
| 길이 보정 참여율 | 평균 참여 시간 ÷ (읽는 시간 × 60초) |
| 완독률 | `article_read` 이벤트 수 ÷ 글 조회수 |
| 다음 글 이동률 | `article_select`(`click_location=next_article`) ÷ 조회수 |
| 반응 수, 반응률 | (`share` + `like` + `scrap`) ÷ 조회수 |
| 재방문 사용자 비율 | GA 사용자 보고서 |

점수 가중치는 초기값이며 데이터 수집 후 조정한다.
 가중치는 초기값이며 데이터 수집 후 조정한다.

| 요소 | 가중치 | 의미 |
|---|---|---|
| 조회수 순위 | 30% | 많이 열렸는가 |
| 완독률 | 25% | 끝까지 읽었는가 |
| 길이 보정 참여율 | 20% | 시간을 들여 읽었는가 |
| 다음 글 이동률 | 15% | 더 읽고 싶어졌는가 |
| 반응률 | 10% | 공유, 좋아요, 스크랩을 이끌었는가 |

- 조회 30회 미만 글은 점수를 산출하지 않고 "표본 부족"으로 구분한다.
- 발행 후 동일 기간(예: 첫 30일)으로 맞춰 비교해 오래된 글이 유리해지는 것을 막는다.

### R7. 관리자 트래픽 제외 개선 `P2`
- 관리자로 로그인하면 이후 이벤트에 `traffic_type=internal`을 부착해 운영자 방문을 구분, 제외할 수 있게 한다.
- 한계: 로그인한 적 없는 브라우저의 운영자 방문은 걸러지지 않는다.

## 7. 후속 범위

| 후속 항목 | 내용 | 선행 조건 |
|---|---|---|
| 글별 지표 대시보드 | 블로그 관리자 화면 안에서 R6의 글별 지표와 인기 글 점수를 표로 제공한다. 데이터는 GA4 Data API를 서버 함수(Cloud Functions)로 호출해 가져오며, 관리자 로그인 계정만 조회할 수 있다. 외부 BI 도구는 사용하지 않는다. | R1~R3 배포 후 최소 2주 데이터 축적, GA 속성에 서비스 계정 조회 권한 부여, 서버 함수 사용 가능한 요금제 |
| 댓글 기능 | 글 상세 화면에 댓글 작성, 조회를 제공한다. 스팸 방지(작성 빈도 제한, 금칙어)와 관리자 삭제, 승인 기능을 포함하고 `comment` 이벤트를 추가한다. 반응 지표에 댓글 수를 합산한다. | R4(익명 인증, 반응 데이터 모델) 안정화, 운영 정책 수립 |
| 스크랩 목록 보기 | 방문자가 스크랩한 글을 모아 보는 목록 화면을 제공한다. 1단계는 같은 브라우저에서 스크랩한 글 목록이고, 2단계로 기기가 달라도 목록이 유지되도록 계정 연동 방식을 검토한다. | R4(스크랩 데이터 모델) 완료, 2단계는 로그인 방식 결정 |
| BigQuery 내보내기 | GA4 원본 이벤트를 내보내 사용자 단위, 경로 단위 분석을 수행한다. | 데이터 축적, 분석 요구 구체화 |

## 8. 비기능 요구

| 구분 | 내용 |
|---|---|
| 성능 | 측정 코드가 화면 표시를 막지 않는다. 스크롤 이벤트는 가볍게 처리한다 |
| 보안 | 반응 기능의 Firestore 규칙은 본인 문서만 쓰기를 허용한다. 관리자 계정 정보는 저장소에 두지 않는다 |
| 개인정보 보호 | 이름, 이메일 등 개인 식별 정보와 익명 인증 ID를 GA 이벤트에 전송하지 않는다 |
| 비용 | 현재 방문 규모에서 무료 사용량 범위 내로 추정하며, 방문량 증가 시 재검토한다 |
