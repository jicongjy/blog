# 글 한 편을 올리는 시간: 구현 전 기준값

PRD 5.1의 "글 한 편을 올리는 시간"은 AI 구현 전과 후를 비교해 30% 단축을 판정한다. 이 문서는 구현 전 값을 어떻게 쟀는지와 한계를 적는다.

## 측정 방법

1. 시도 1: Claude가 브라우저를 자동 조작해 쟀다. 결과 0.81초. 입력이 즉시 끝나는 자동 조작 속도라서 사람이 제목과 요약을 정하는 시간이 들어 있지 않다. 기준값으로 쓰지 않는다.
2. 시도 2(채택): 로컬 미리보기 모드의 에디터(실제 블로그와 데이터에 영향 없음)에 시험용 본문(218자)을 미리 채우고, 홍지영이 직접 제목, 요약을 쓰고 발행을 눌렀다. 시간은 페이지 안의 타이머가 쟀다. 시작은 제목 칸의 첫 입력, 끝은 발행 버튼 클릭이다. 생각하는 시간이 빠지지 않도록, 홍지영이 제목을 떠올리기 시작하는 순간 제목 칸에 아무 글자나 먼저 입력해 타이머를 시작했다.

## 결과

| 항목 | 값 |
|---|---|
| 걸린 시간 | 77.8초 (한국 시각 2026-11-24 11:38:48 ~ 11:40:06) |
| 제목 길이 | 25자 |
| 요약 길이 | 93자 |
| 카테고리 | 기본값(기획) 그대로 |
| 표지 이미지 | 비움 |

## 한계

1. 타이머 시작은 홍지영이 직접 한 입력이다. 생각을 시작하는 순간 바로 입력했다는 것은 본인 보고이고, 타이머가 이를 검증하지는 못한다.
2. 시험 글은 Claude가 쓴 본문이라 직접 쓴 글보다 제목과 요약을 정하기 쉽거나 어려울 수 있다.
3. 한 번만 쟀다. 구현 후 값과 같은 조건(같은 방식, 같은 시험 본문)으로 한 번 더 재서 비교하므로, 결과에는 한 번의 비교라는 점을 함께 적는다.
